# 试听工作台与 Spectral Peaks

本轮参考用户提供的 REAPER Media Explorer 与 Peaks Display Settings 截图，采用柔和的炭灰界面、灰青操作色与浅灰文字，减弱亮薄荷绿高亮，同时保留面板、选中项和按钮的层次。普通 Waveform 也使用灰青色，彩色频谱保留单独的灰色底板以衬托黑色噪声轮廓。传输控制移到 Waveform 上方，源时间、文件名和格式位于下方，增加时间尺、水平缩放/滚动、完整声音视图及显示设置。按钮使用项目内 SVG，避免系统字体缺字。1080×700 小窗口压缩波形高度，并允许展开的高级筛选纵向滚动，保持底部时间与缩放控件可见。

## 播放行为

- 声音列表底部的“单击播放”默认开启：普通单击选中并立即播放；取消勾选后单击选中并查看 Waveform，双击试听。选项随偏好保存，已保存的关闭选择保持不变；Ctrl／Shift 多选、右键菜单、拖出文件和缺失记录不触发播放，方向键仍只改变选择。
- Metadata 保存等后台刷新若仍显示相同顺序的同一批对象，会保留行控件的双击状态；对象身份、顺序或数量改变时重新建立列表，避免把刷新前后不同对象的点击合并。
- Pitch：−24～+24 半音，支持小数；Rate：0.25～4.0 倍。输入后按回车应用，重置按钮恢复 Pitch 0 / Rate 1。
- Pitch 保持原时长；Rate 保持原音高。SoundTouch 2.3.2 使用设备采样率 PCM，在控制线程流式处理选定监听声道对。默认值绕过处理器，输出回调仍只消费有界 PCM。
- 修改设置从确认的源位置重建处理流；暂停状态保持暂停。波形时间尺、定位、播放位置均采用源秒数；Rate 2.0 时源位置按约两倍速度前进。
- Mono 将监听左右声道按 `(L+R)/2` 混合，再送到两个监听输出。循环按钮在存在 Waveform 选区时重复选区，否则重复整个声音，不新增文件播放历史身份；当前是控制线程重启式循环，不承诺无缝片段循环。
- 音量为 −60～0 dB，最左端静音。显示增益只改变 Waveform 高度。
- Seek 在设备采样率下对每声道使用 32 个输出采样点的线性淡出/淡入，左右监听声道共用同一包络，独立于音量的 5ms 平滑。控制线程等旧位置淡出到零后再替换解码流；定位过程中设备保持输出静音，防止暂停丢弃已排队的淡出尾段。旧缓冲不足时，回调衰减最近真实立体声样本完成尾段，合成帧不推进源位置；换源及普通静音会清除尾样本。新位置从零起音，暂停时定位则在下次 Play 才推进淡入。Stop 等已排队的淡出尾段排空后暂停设备。连续定位用修订号拒绝旧回调的淡出确认，不改变源时间定位或播放历史会话规则。源 WAV 保持只读。
- 已确认的 Pitch/Rate/Mono/循环设置随偏好保存。退出前的同步命令等待此前控制命令完成。显示设置和缩放保留在当前会话，选择新文件时恢复全览。
- 播放头使用 1px 细竖线，不再显示顶部粗标记，已播放的可见区域覆以轻遮罩和底部进度线。Slint 的逐帧时钟在两次引擎回报之间按已确认 Rate 补齐移动，小幅校正连续过渡；预测最多延伸 100ms，重复位置不重启时钟，输出停滞时不继续跑。引擎的独立传输修订号使暂停、停止、任意 Seek、循环、换源、处理流重建和确认 Rate 变化对齐确认位置，包括两次轮询之间已完成的短声音循环。加载 generation 与播放历史会话身份保持原语义。动效仅在 UI 层处理，时间读数和辅助功能值仍为引擎确认的源时间。
- 鼠标悬停 Waveform 或下方时间尺时，滚轮向上放大、向下缩小，支持触控板的连续像素增量。缩放以鼠标横向位置对应的源时间为锚点，保持它在视口中的比例，接近源文件边界时夹取视口。快速连续操作累计目标缩放倍数，并始终从当前显示范围计算源时间，避免异步渲染尚未完成时锚点漂移。范围为 1～128 倍；滚轮不定位、不改变播放状态。原有缩放按钮、滚动条和完整声音视图继续可用，单击 Waveform 或时间尺会定位到当前可见范围内的点击位置，并立即开始或继续播放；暂停、停止与播放结束后同样适用。定位与播放在音频控制线程作为一个有序命令处理，定位失败不会继续播放旧位置；单独的 CLI Seek 和返回起点按钮保留原有播放状态。

CLI 可复现相同设置，例如 `AudioLibCli.exe audition --pitch 7 --rate 0.5 --mono`；不带选项恢复默认试听设置。CLI 播放操作要求正在运行的桌面实例。

## Waveform 选区与 WAV 切片

经典与现代播放器共用选区行为。鼠标在 Waveform 上拖动框选，允许从右向左选择；松开后从选区起点自动试听，到终点停止。选区显示起点、终点和时长，两端可直接拖动调整，松开后重新试听。选区内部拖动用于向资源管理器、Finder 或 DAW 导出切片；按住 Shift 拖动可在选区内部重新框选。未达到拖动阈值的单击仍定位并播放，点击选区外会先清除选区。

光标表达当前可执行的操作，Waveform 下方的独立操作条显示切片准备进度与结果。经典与现代播放器、展开与紧凑视图使用相同状态；操作条不覆盖音频峰值或时间尺。宽度不足时保留拖出手柄、时长和按钮，完整起止时间通过辅助描述查看。

| 位置或阶段 | 光标与反馈 | 操作 |
| --- | --- | --- |
| 选区外悬停 | 中心留空的细十字 | 拖动框选，单击定位播放 |
| 正在框选 | 横向准线贯穿纵向虚线定位轴与实线范围外缘，按拖动方向镜像；实时更新读数 | 松开试听，Esc 放弃本次框选 |
| 起点或终点 | 带端点标记的横向调整图标；对应边界加强对比 | 拖动调整，松开重新试听 |
| 选区内部或拖出手柄 | 开放手形与文件标记 | 拖出 WAV；Shift 拖动重新框选 |
| 按下导出区域 | 闭合手形 | 超过 6 个逻辑像素才请求导出，短单击仍定位 |
| 保持拖出但文件未就绪 | 闭合手形加等待标记；操作条显示进度 | 保持按住，或松开后待就绪再次拖出 |
| 后台准备，无导出手势 | 保持当前框选、调整或导出指针 | 继续编辑选区，或单独取消准备 |
| 原生拖放 | 系统复制或禁止放置反馈 | 目标程序决定是否接收，Esc 取消拖放 |
| 取消或失败 | 恢复当前位置的操作光标；保留结果提示 | 再次拖出可重试，清除按钮始终清除选区 |

当前手势优先于手柄悬停，后台准备不会夺走可用操作的光标。源不可用时恢复普通指针与原因提示；仅音频可用时保留单击定位。选区两端采用 1px 细线和上下短刻度，命中范围仍为两侧各 5 个逻辑像素（随界面缩放）。绘制或调整期间暂停自动跟随并冻结手势开始时的源时间映射；缩放、平移和主题重绘保留源时间选区。实际显示源、资料库或服务器身份改变会取消旧准备并清除选区。

指针图形统一使用 20×20 SVG，保持 20 个逻辑像素，独立于应用 GUI 缩放；系统 DPI 决定物理像素尺寸。支持的 winit 后端在输入处理结束后设置自定义系统光标，状态变化不依赖下一次鼠标移动；其它后端使用同图绘制回退。原生光标按目标物理尺寸直接从 SVG 栅格化，避免放大低分辨率位图；热点按同一次取整后的尺寸换算。缓存仅保留当前系统 DPI 的一组指针。原生拖放前恢复系统指针，返回后结束本次手势并恢复当前命中反馈。

选区绑定当前显示的 Waveform 源，即使 Metadata 详情面板已选中另一素材，也从画面所对应的声音试听和裁剪。范围按原素材采样帧保存为半开区间 `[start_frame, end_frame)`，选区终点的采样帧不导出。自动试听与 Metadata 写入顺序、Stop 和换源共用播放 admission；Stop 取消尚未执行的自动试听，已选范围与切片准备仍可保留。Stop 回到选区起点，结束后再次 Play 从选区起点开始；暂停、恢复以及 Pitch、Rate、Mono 或设备设置变化保持范围。循环启用时只重复该范围。

第一次框选与第二次拖出是两个手势。提交选区后先在后台准备 WAV；若开始拖出时尚未完成，显示下载或裁剪进度。准备完成后鼠标仍按住才进入原生文件拖拽，已经松手则提示再次拖出。Esc 先取消当前手势，没有手势时取消准备并保留选区，再按可清除范围。操作条的“取消”只取消准备，`×` 始终清除选区；两者不随阶段交换含义。原生拖放成功、取消或失败后均显式结束手势，选区与可复用的切片仍可保留。

### 输出目录、命名与生命周期

默认保存到系统文档目录下的 `AudioLib Explorer/Exports`。设置界面的“快速导出”区域可选择其他保存目录，偏好键为 `slice_export_directory`；更改目录不会移动已经导出的文件，当前选区下次拖出时在新目录重新准备。

导出统一命名为 `原名_slice_001.wav`、`原名_slice_002.wav` 等，保留中文并清理文件名中的非法字符。每次成功导出使用首个未占用序号，独占创建，不覆盖同名文件。只有原生拖拽目标接受复制后才保留该文件；正常取消或失败会删除本次未交付的文件。成功交付的 WAV 长期保留在保存目录中，DAW 可以持续引用；文件拥有独立字节，DAW 原地编辑它不会改变后续导出使用的准备结果。

准备文件放在保存目录下带拥有标记和文件锁的 `.audiolib-slice-*` 临时子目录中；换源、重新框选、取消或正常退出会释放本次准备。创建新准备目录时，仅回收超过 24 小时、拥有标记和目录内容完整匹配且未被其他实例锁定的遗留目录；未知文件、链接和重解析点保留。已交付的 `*_slice_*.wav` 不属于该临时目录清理范围。关闭会取消尚未完成的工作并等待工作线程释放拥有文件，同时沿用现有 Metadata、扫描与偏好持久化顺序。

### 原素材与采样精度

裁剪始终保留原采样率和全部源声道，忽略试听 Pitch、Rate、音量、Mono、监听声道对和 Waveform 显示增益。服务器模式从原素材 `/audio/{id}/stream?download=1` 准备完整原件，可复用已验证的原文件缓存；不会将低采样率预览或试听缓存当作导出来源，无需新增服务端裁剪接口。原件不可取得时明确失败，不退回低质量预览。下载版本绑定 ETag，准备前将完整原件固定到本次拥有的 staging 副本，避免原文件缓存淘汰影响裁剪。

远程显示源同时绑定原件强 ETag 和字节长度。分段 Waveform 使用独立的原件版本缓存和精确版本凭据，分段读取前后核对原件，避免快照未更新时混入已替换的音频；旧版未知来源缓存不能直接作为切片依据。试听表示核对自身 ETag 和对应原件版本，导出原件也必须匹配该显示版本。离线使用只接受已有版本凭据的原件与 Waveform；版本无法证明或原件已变化时明确提示重新加载。

| 原素材类型 | WAV 输出 |
| --- | --- |
| PCM / IEEE float WAV、BWF、RF64 / BW64 | 按源帧保留采样字节、位深、有效位和声道布局，按输出大小重建 RIFF 或 RF64 |
| 支持的 AIFF / AIFF-C PCM 或浮点 | 保留采样精度、采样率和全部声道，仅转换 WAV 所需的字节序与 8-bit 符号表示 |
| FLAC | 直接使用整数解码结果，保留原有效位深，避免经过试听 `f32` 通路损失 32-bit 整数低位 |
| MP3、Ogg Vorbis、支持的压缩 WAV | 按原素材呈现时间轴精确 Seek / 解码，写出 32-bit float WAV；这是解码音频裁剪，不是原压缩包字节复制 |

试听可继续使用服务器预览。原素材范围向播放表示采样率转换时向内对齐；低采样率表示不足以容纳所选区间时改用原流。区间终点在重采样输入处作为 EOF，SoundTouch 只接收范围内采样；必要的重采样补零和处理尾部受最终输出帧预算限制。压缩格式可能为边界 Seek、预滚和完整包解码而读取区间外的压缩字节，但范围外采样不进入试听处理和输出。

变速或变调的 SoundTouch 实例由音频控制线程独占，在固定地址构造，并在重选、定位、停止、循环和换源释放旧实例时配对执行原生析构。Windows 同样释放内部处理缓冲，避免高层包装器在该平台缺少析构而随反复试听积累内存；默认 Pitch 0 / Rate 1 不创建该处理器。原生 SoundTouch 版本和试听算法保持不变，音频回调不持有或销毁该对象。

首版导出仅重建必要的音频结构，不复制源文件嵌入的描述、封面、cue、循环标记、BEXT、iXML 或未知厂商块，避免携带错误的偏移、长度和时间引用。原素材、数据库 Metadata、用户标签与注释保持不变；导出的音频精度保证不表示导出文件包含原嵌入式 Metadata。

### 验证边界

新增回归包含区间外强脉冲隔离、不同设备采样率与 Pitch / Rate、循环与 Stop、原帧及位深保持、显示 A 而详情为 B 的源身份、恢复 Waveform 而音频尚未加载或试听素材更短时的源时间框选、手势中时长与视图变化、延迟原文件下载遇到换源、取消重试和临时目录拥有边界。测试文件与数据库使用隔离临时目录；具体执行结果以本次实际验证记录为准，不沿用本节以后的历史结果作为新功能通过证据。

桌面启动时在当前数据目录的日志文件夹中预开 `AudioLibExplorer-panic.log`。Rust panic 发生时，同步尽力写入线程、源码位置和回溯并落盘，再调用原有日志与默认 hook，避免异常中止时异步日志尚未刷新。该诊断省略 panic payload、配置和运行参数；打开或写入失败不影响正常启动。它用于定位 Rust panic，不能代替原生访问冲突或内存耗尽的系统诊断。

原生文件拖出已有 Windows 和 macOS 适配；Linux 当前明确返回不支持。资源管理器 / Finder 与实际 DAW 的接收、释放鼠标后的文件可读性及后续引用，需要在对应平台分别验收；编译或 Windows 测试结果不能代替 macOS 原生拖拽验收。

## 颜色与分析

REAPER 手册说明：Spectral Peaks 的色相依据主导频率，饱和度依据声音的纯音程度；启用“Fade non-tonal content to theme peaks color”时，非音调内容会淡化到普通波形颜色。根据用户的最终效果截图，本实现采用近黑色普通峰值基底，宽带噪声和冲击瞬态不显彩色。这一视图保留振幅轮廓，不等于完整频谱图。

本实现使用居中的双尺度 Hann 窗 FFT。约 20～40 ms 短窗保留打击与挤压声音中的短促共振；低频主峰使用长窗回退，分辨率约 5～10 Hz。短窗 hop 为窗长的 1/4，低频长窗结果最多复用 1/4 长窗时间，限制分析开销。从功率最大的非 DC 频点做对数功率抛物线插值。从峰附近五个频点的能量中扣除两侧频点估计的宽带背景，再除以总能量作为纯音程度。同一显示桶内使用按纯音程度平方加权的对数频率平均，避免随机噪声频点拉偏短暂音调的颜色。PCM、分析窗口和输出块均有界，不一次读入整个 WAV。

颜色按用户提供的 REAPER Peaks Display Settings 色带校准，依次为紫红、红、黄、绿、青绿、蓝、紫，RGB 按对数频率平滑插值。调色板端点使用最高通道 255、最低通道 0 的鲜明配色，替换原来的柔和低饱和调色板，并纠正旧色带与参考图的色相偏移。显示设置中的色带使用相同端点和频率标签；此调整不改变频率分析、显色门限、振幅轮廓或播放音量。截图最后一个可见标签之后的高频颜色按同一色带继续过渡；本实现是参考图校准，不宣称与 REAPER 内部算法逐像素相同。

| 14 Hz | 紫红 | `#FB00FF` |
| 36 Hz | 红 | `#FF0018` |
| 93 Hz | 黄 | `#FFD300` |
| 241 Hz | 绿 | `#3DFF00` |
| 628 Hz | 青绿 | `#00FFAC` |
| 1632 Hz | 蓝 | `#0064FF` |
| 4241 Hz | 紫 | `#8600FF` |
| 11025 Hz 及以上 | 粉红 | `#FF0094` |

噪声阈值设置显色门限（默认纯音程度 0.06），频率分散控制门限之上达到完整颜色的证据范围；归一化显色权重采用平方曲线，弱证据仍接近黑色。显色权重同时降低彩色峰的亮度，连续淡化到 `#0E0E0E`，不再做亮灰混合或平方根提升。色彩强度也向同一黑色基底混合，因此改变强度不会把噪声漂白。彩色模式使用较亮的灰色波形底板，保证黑色轮廓清楚；普通模式使用深灰底与灰青波形。它们是本实现的显示参数，不宣称数值与 REAPER 内部公式完全相同。原始声音的颜色不受试听 Pitch/Rate 改变。

噪声阈值和频率分散保存到本机 `settings.json` 的 `spectral_peaks`，后台自动保存，退出时写入最后的值；启动时同时恢复滑动条和实际 Waveform 渲染参数。最小值分别为 0.1 和 0.05，旧设置缺少该项时沿用 1.0 和 0.38。设置与资料库、服务器凭据分开，显示增益、模式、强度和缩放仍只作用于本次会话。

Waveform 缓存算法为 v4，包含扣除宽带背景后的纯音程度；v3 的灰色噪声结果及更早版本的缓存自动失效，无需手动删除缓存。调色板调整沿用 v4 分析结果，读取时从主频和纯音程度刷新 RGB，无需重新解码音频或进行 FFT。后台请求保留取消和 generation 校验，图像、时间尺和点击定位范围在事件循环一起发布。

服务器模式的彩色 Waveform 按可见源时间范围逐段请求，首段约 0.5 秒（向上对齐显示桶；全览长文件时至少一列），首段返回立即显示，后续有新结果时约每 500 ms 发布一次，完成时立即发布。未加载部分留空，已加载部分保持在完整时间轴上的正确位置；信息栏显示已加载百分比。后续批次逐步扩大至约视口的 1/16，避免长音频产生数千次外网请求。网络或服务端分析慢时不保证每 500 ms 都有新数据。

分段使用现有 `/audio/{id}/waveform` 范围接口，无需服务器升级。音频流和 Waveform 仍由独立后台流程处理；仅首个无缓存分段为音频预缓冲让路，最多等待 3 秒，内存命中直接复用，磁盘按分段 ETag 重验证。缩放、平移、切换素材会取消旧请求，并在 Slint 事件循环再次核对 generation。分段失败保留已显示结果并报告错误，不把残缺结果标为完成；本地文件仍使用原有完整 Waveform 缓存。分段边缘的频谱分析窗口独立，颜色不保证与一次完整分析逐像素一致。

服务器分段进入缓存前验证原始帧范围和峰值结构，损坏缓存会重新请求，异常响应不会阻断同一 revision 的正常重试。切换到缺失素材也立即取消旧 Waveform。试听回退仍映射到原始时间轴；降采样后的不足一帧尾段保留为空列。

## 验证与边界

自动回归覆盖频率锚点、不同采样率/幅度/随机种子的白噪声与单样本冲击保持黑色、混合信号的单调显色、缩放及缓存重建后黑色保持、显示层强度/增益不漂白噪声，以及变调/变速独立性、定位后长度、0.25～4 倍速和 ±24 半音、Mono 抵消、显示范围约束、dB 转换及传输按钮行为。`tools/validate-playback-ipc.ps1` 增加暂停时变调/变速、非法参数保护及 4 倍速循环检查。

`tools/validate-spectral-ui.ps1` 在隔离资料库中生成中英文主界面、1080×700 界面、显示设置及七频率＋白噪声及 −20/−10/0/+10 dB 音调噪声比样本截图。测试文件只写入 `.rust-validation/spectral-v4`；源 WAV 和原始资料库保持不变。版本检查结果见 [Rust 验证报告](Rust_Validation.md)。极端变调/拉伸可能产生音质变化；尚未进行听感盲测或按钮到模拟输出的延迟测量。

## 真实素材对照（0.3.1）

用户提供的 `Example_Impact_1.wav` 为 96 kHz / 24 bit / 双声道，长度 2.296 秒。只读分析原文件，并在隔离资料库扫描其副本生成实际 GUI 截图。原文件 SHA-256 验证前后保持不变。

对照发现，单一长窗会把这段声音的短促共振抹掉，因而采用短窗保留瞬态音调、长窗辅助低频。实际波形主体为黑色，局部短促共振显色；同时用七个纯音、白噪声和四种音调噪声比检查，噪声占主导的段保持黑色。数值和发布版界面证据见 修正验证记录 与 截图清单。这里只对照原 WAV，未加载 REAPER 工程的 FX 或片段包络，不宣称与其内部算法逐像素一致。
